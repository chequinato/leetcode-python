## Como usar

1. Escolha um exercício da lista.
2. Abra o arquivo correspondente na pasta da categoria.
3. Implemente a solução em Python.
4. Teste com exemplos do LeetCode.

## Organização dos conceitos

- Two Pointers / Sliding Window: arrays e strings
- Hashing: busca rápida O(1)
- BFS/DFS: árvores e grafos
- Binary Search: arrays ordenados e variações
- Backtracking: combinações e permutações
- DP (1D e 2D): otimização e contagem de formas
- Heap: top K e streaming de dados
- Greedy: decisões locais ótimas
- Bit Manipulation: truques de baixo nível
